==========================================================================
  飞牛 fnOS 本地测试环境  ·  使用说明
==========================================================================

一句话说明：这个软件能在你的 Windows 电脑上"模拟"出一台飞牛 NAS，
让你不买真机器就能安装飞牛系统、测试 FPK 应用。

--------------------------------------------------------------------------
一、它是什么 / 能做什么
--------------------------------------------------------------------------
· 在你电脑上开一个"虚拟的飞牛 NAS"，功能和真机基本一致。
· 可以安装飞牛系统镜像（ISO），也可以随时换成别人的系统盘。
· 可以把 .fpk 应用装进去，然后像在真机上一样，用电脑浏览器打开应用界面。
· 全部组件已经打包在一起，不需要你另外安装任何软件（不用装 Python、不用装虚拟机软件）。
· 支持 Windows 10 / 11 的 64 位电脑。
· v1.2 新功能：步骤完成会显示绿色对勾提示；一键保存/还原初始状态；一键删除虚拟机；
  启动虚拟机不再弹出多余命令行窗口。
· v1.3 新功能：程序启动时自动检测是否已有虚拟机在运行；若已运行会在顶部显示绿色横幅，
  提示前面功能都正常，可直接点「打开飞牛管理界面」进入后台。程序崩溃重启后也能自动接管。
· v1.4 重要修复：彻底解决程序闪退（0xc0000409）。根因是打包程序启动虚拟机时用了
  CREATE_NO_WINDOW 隐藏窗口，与程序自身争用运行库导致崩溃；现改用安全方式隐藏窗口，
  并把打开浏览器、协议探测都改为不触发崩溃的实现。
· v1.5 修复：解决"提示虚拟机已启动但画面窗口不弹出"。因为隐藏命令行窗口时把虚拟机
  图形窗口也一起隐藏了；现会在图形窗口出现后自动把它显示出来，命令行黑窗仍保持隐藏。
· v1.6 界面调整：所有功能按钮（启动/停止/打开管理界面）统一放到左侧「快捷操作」区；
  右上角只显示运行状态和管理地址；系统盘、数据盘可在自定义位置一次同时创建；
  所有后台窗口（命令行黑窗、串口窗）全部隐藏，只保留虚拟机画面窗口。
· v1.7 画面嵌入：虚拟机的实时画面直接嵌进软件窗口里，不再单独弹出任何窗口！
  点左侧「🖥 虚拟机画面」即可查看并操作（安装系统时就在这个画面里点下一步）。
  命令行黑窗、串口窗等所有后台窗口全部隐藏，桌面上只保留软件这一个窗口。
· v1.8 重要修复：解决"换了存储位置后，启动的是一台空虚拟机，管理界面一直打不开"。
  原因是软件在新建硬盘时会把同名文件覆盖掉，导致原来装好系统的盘被闲置。
  现在做了三层保护：
    ① 创建硬盘时，若该位置已有可用系统盘，直接复用它，绝不覆盖、不丢数据；
    ② 若该位置没有，软件会自动扫描电脑上已有的系统盘，并询问你是否直接使用它；
    ③ 启动前会检查系统盘，如果是空盘（还没装系统），会提示你切换到真正的系统盘。
  另外，创建/复用硬盘后会立即写入配置，不用再手动点"保存设置"。
· v1.9 修复：解决"嵌入的画面点鼠标没反应、装系统时点不动下一步"。原因是虚拟机
  只接了 PS/2 相对鼠标，嵌入窗口里无法触发鼠标捕获。现在改为接入 USB 绝对定位
  鼠标（tablet）+ USB 键盘，鼠标位置直接对应，点哪里就是哪里，无需按 Ctrl+Alt+G。
  同时修复了键盘焦点问题，并新增「⧉ 弹出为独立窗口」按钮：
  万一嵌入画面里操作仍有异常，点一下这个按钮，画面会弹成普通独立窗口，
  在里面操作完再关掉软件重开即可。
· v2.0 新增：应用端口自动转发。在虚拟机上装的应用（下载器、影音库、相册、
  网盘等）都能直接用浏览器打开 http://localhost:端口。左侧新增
  「⇄ 应用端口转发」页面，可以查看、添加、移除端口，虚拟机运行中改完立即生效、
  不用重启；启动时还会自动转发一批常见应用端口（8080 / 8096 / 5244 / 5700 /
  9000 等），与本机其它程序冲突的端口会自动跳过并写进日志。
· v2.1 改进：端口转发列表会主动检测"端口背后到底有没有应用在跑"。
  状态显示「可访问」= 转发通了、浏览器能打开；
  显示「已转发·应用无响应」= 转发本身没问题，是虚拟机里那个应用没启动、
  或者端口填错了。这时去飞牛「应用中心 → 该应用 → 详情」核对真实端口，
  必要时先在飞牛桌面上打开一次该应用（应用要先运行起来，端口才会监听）。
· v2.2 修复：点「停止虚拟机」却提示"虚拟机未在运行"，但飞牛其实是开着的。
  原因是程序重启后只认"自己启动的"虚拟机，没有真正接管之前那个。
  现在打开软件会自动接管已在运行的虚拟机，并每 4 秒对齐一次状态，
  「停止虚拟机」可以直接关闭它；接管后端口转发、画面嵌入也都正常可用。
· v2.2.2 重要修复（三个连带问题）：
  ① 关闭软件时，嵌入的虚拟机画面窗口会被一起销毁，导致"虚拟机还在跑，
     但再也看不到画面"。现在关软件时会把画面还原成独立窗口，虚拟机照常运行。
  ② 关闭软件会导致虚拟机意外退出（输出管道断开所致）。已改为写入日志文件，
     关软件不再影响虚拟机，下次打开软件会自动接管。
  ③ 画面嵌入偶发失败（窗口句柄 64 位溢出），已修正，嵌入更稳定。
· v2.3 新增：一键「扫描应用端口」。它会在虚拟机里逐个试探，把真正在监听的
  端口列出来（约 10 秒），确认后自动全部添加转发。以后装了什么应用都不用
  再去查端口号，也不用猜——点一下扫描即可。飞牛自带的应用很多走 5000 段
  （例如 Docker 管理器在 5024），并不总是常见端口。

· v2.4 新增「单文件版」：整个软件（含虚拟机引擎）打包成一个 exe，双击即可用，
  不再有一堆文件夹和 bat 文件。首次启动会自动解压运行环境（约 30 秒，只做一次），
  之后启动就和普通软件一样快。详见「二点六、单文件版怎么用」。

--------------------------------------------------------------------------
二、第一次使用（从零开始，照着做即可）
--------------------------------------------------------------------------
软件左侧有 6 个步骤，按顺序点着做。
※ 左侧顶部「快捷操作」区有 启动虚拟机 / 停止虚拟机 / 打开管理界面 三个按钮，随时可用。
※ 右上角显示"运行状态"和"管理地址"，虚拟机启动后点地址或左侧按钮即可进入飞牛后台。

【第 1 步】环境自检
  1. 双击运行"飞牛fnOS本地测试环境"图标启动软件。
  2. 点左侧"1. 环境自检"，再点"重新检测"。
  3. 只要看到 QEMU 主程序、虚拟硬盘工具、引导固件都是"通过"，就说明没问题。
  4. 如果"Windows 硬件加速"显示"未启用"也没关系，只是速度慢一点，可以正常用。

【第 2 步】准备镜像
  这一位是准备"飞牛系统安装盘"。
  1. 点"打开飞牛官网下载"按钮，浏览器会打开飞牛官网。
  2. 在官网下载 x86_64 的 ISO 安装镜像（一般是 .iso 文件，几个 GB）。
     官网地址也可手动输入：https://www.fnnas.com/download
  3. 回到软件，保持选中"全新安装（使用 ISO 安装镜像）"。
  4. 点 ISO 一行后面的"浏览..."，选中刚下载的 .iso 文件。
  5. 在"创建虚拟硬盘"区：
     - 存储位置：点"选择文件夹…"选一个你自己的文件夹（默认在程序的 fnnas-data 目录）。
     - 系统盘（GB）：默认 64，够用。
     - 数据盘（GB）：默认 64；填 0 表示不创建。飞牛需要数据盘才能创建"存储空间"，建议保留。
     - 点"同时创建两块硬盘"，会一次创建好系统盘和数据盘，都放在你选的文件夹里。
  6. 点左侧"3. 虚拟机设置"，再点"保存设置"。

【第 3 步】虚拟机设置
  一般不用改，保持默认即可。
  · 建议 CPU 4 核、内存 4096MB 以上。
  · 如果提示端口被占用，把 Web 管理端口从 5666 改成别的（比如 5667）。

【第 4 步】启动并初始化飞牛系统
  1. 点顶部或本页的"启动虚拟机"，等待进入飞牛安装界面。
  2. 按安装向导：选择把系统装到刚才建的系统盘，开始安装。
  3. ★重要★ 安装进度到 99% 时，安装器会停下来等你确认！
     此时请点一下软件左侧「🖥 虚拟机画面」里的画面，按屏幕提示点击"下一步 / 确认 / 重启"
     继续（安装中途有需要人工点击的步骤，不是卡死）。
  4. 按提示确认重启，等待系统重新启动，直到控制台出现
     "localhost login:" 或显示 Web 管理地址，说明安装完成。
  5. 点"打开飞牛管理界面"（程序会自动判断用 http 还是 https）。
     ※ 如果浏览器提示"证书不受信任 / 不安全"是正常的，点"高级"→"继续访问"。
  6. 按页面提示设置设备名、管理员账号和密码。
  7. 进入飞牛桌面，恭喜，你的"虚拟 NAS"已经跑起来了！

  ※ 访问地址也可手动在浏览器输入：http://localhost:5666
    （如果改过端口，用你设置的端口；控制台里显示的 10.0.2.x 是虚拟机内部地址，
     在 Windows 上要用 localhost 访问，不能用那个 10.0.2.x 地址。）

【第 5 步】安装 FPK 应用
  方法 A（最简单，推荐）：
  1. 在飞牛桌面打开"应用中心"。
  2. 点右上角菜单（三个点）→"安装本地应用"。
  3. 选择你的 .fpk 文件，按提示装完即可。

  方法 B（命令行，适合调试）：
  1. 在本页点"浏览..."选择 .fpk 文件，点"复制安装命令"。
  2. 用 Windows 终端 SSH 连接：点"复制 SSH 连接命令"并粘贴运行。
  3. 再把安装命令粘贴进去执行。

【第 6 步】打开应用界面
  1. 点"打开飞牛桌面"，登录后点对应应用图标，界面会在浏览器新标签页打开。
  2. 如果应用有固定端口/地址，可填到"访问地址"里，点"打开"。

二点五、v1.2 / v1.3 新增功能
--------------------------------------------------------------------------
【v1.3 自动检测已运行的虚拟机】
  程序启动时会自动检查是否已有飞牛虚拟机在运行（例如上次打开后没关，
  或程序意外闪退重开）。若检测到，顶部会出现绿色横幅：
  "检测到飞牛虚拟机正在运行（前面功能都正常），可直接点击打开管理界面"，
  6 个步骤全部显示绿色对勾，点横幅右侧按钮或顶部"打开管理界面"即可直接进入后台，
  无需重新启动虚拟机、无需重装系统。

【v1.2 功能】（第 4 步"启动与初始化"页面里）
【绿色成功提示】
  每完成一个步骤（环境自检、镜像就绪、设置保存、系统就绪、选好 FPK），
  左侧步骤号后面会出现绿色对勾 ✓，顶部显示"完成进度 x/6"，
  右侧内容区顶部会出现绿色成功提示条，让你清楚知道做到哪了。

【保存为初始状态 / 一键还原初始状态】
  · 装好系统、配置好常用环境后，先停止虚拟机，点"保存为初始状态"。
  · 以后无论怎么折腾（装错应用、改乱设置），只要点"一键还原初始状态"，
    系统就会秒级恢复到保存时的样子，不用重装。
  · 注意：保存和还原都必须先停止虚拟机；还原会清掉初始状态之后的所有改动，
    重要数据请另行备份。

【一键删除虚拟机】
  · 先停止虚拟机，再点"一键删除虚拟机"。
  · 程序会列出将删除的文件和大小，请你确认两次。
  · 默认"安全删除"：文件会移到 fnnas-data 下的 backup-日期 文件夹，可随时找回；
    也可选"永久删除"。删除后可回到第 2 步重新开始。

二点六、单文件版怎么用（v2.4）
--------------------------------------------------------------------------
单文件版只有一个 exe，虚拟机引擎已经压在这个 exe 里面，不用再带一堆文件夹。

1. 把这个 exe 放到一个**固定位置**，例如 D:\飞牛测试\
   ※ 别放桌面或临时目录，因为数据和运行环境会在它旁边生成。
2. 双击运行。首次启动会出现"正在准备运行环境"的进度条，约 30 秒，
   之后会把引擎解压到 C:\Users\Public\Documents\fnnas-qemu-runtime-v1\。
   这一步**只做一次**，以后启动直接进界面。
3. 装过系统的用户：把原来文件夹里的 fnnas-data 整个目录复制到 exe 旁边，
   打开软件就能直接沿用它原来的系统盘，不用重装。
4. 全新用户：照「二、第一次使用」的 6 个步骤做即可。

几个要点：
· 首次启动需要约 800 MB 磁盘空间（解压出来的引擎）；
· 想换电脑带走，只需带走这个 exe 和 fnnas-data 目录；
· 如果系统重装或删掉了上面那个解压目录，再次运行会自动重新解压，不影响系统盘数据；
· 单文件版和文件夹版功能完全一致，两种可以并存。

--------------------------------------------------------------------------
三、以后再使用（不用重新安装系统）
--------------------------------------------------------------------------
1. 打开软件 → 第 2 步 → 安装方式选"使用已有系统盘"，确认系统盘路径正确。
2. 点顶部"启动虚拟机"。
3. 点"打开飞牛管理界面"，输入上次的账号密码登录即可。

--------------------------------------------------------------------------
四、如何"更换飞牛系统镜像"
--------------------------------------------------------------------------
有两种更换方式：

方式 1：换安装镜像（ISO）
  第 2 步 → ISO 一行点"浏览..."选新的 .iso → 安装方式选"全新安装" →
  在"创建虚拟硬盘"区点"同时创建两块硬盘" → 保存设置 → 启动，按向导重装。

方式 2：直接用别人的系统盘（最快）
  把别人做好的 .qcow2 系统盘文件放到电脑上，
  第 2 步 → 点"系统盘"后面的"浏览..."选中它 →
  安装方式会自动变成"使用已有系统盘" → 保存设置 → 启动即可。
  ※ 每块系统盘的 UEFI/引导设置是独立的，切换互不影响。

五、常见问题
--------------------------------------------------------------------------
Q：打开管理界面一直转圈 / 打不开？
A：先确认顶部状态显示"虚拟机运行中"；首次装完系统要 1~3 分钟 Web 服务才起来。
   可手动在浏览器试 http://localhost:5666 和 https://localhost:5666（端口改过就换端口）。
   注意不能用控制台里显示的 10.0.2.x 地址访问，Windows 上要用 localhost。
   ※ 若等了 5 分钟仍然打不开：多半是选中的系统盘是一块空盘（里面没系统）。
     到第 2 步看看"系统盘"路径，文件只有几百 KB 就是空盘；改用之前装好系统的
     那块盘（通常有几个 GB）即可。v1.8 起启动前会自动检查和提示。

Q：安装进度到 99% 就不动了 / 屏幕黑屏？
A：这不是卡死。飞牛安装到 99% 时需要人工确认，请点一下 QEMU 虚拟机窗口，
   按屏幕提示点击"下一步 / 确认 / 重启"，安装即可继续完成。

Q：浏览器提示不安全？
A：如果用的是 https 访问，飞牛自签名证书会提示不安全，选"继续访问"即可；
   也可改用 http://localhost:5666 访问。

Q：安装时找不到硬盘 / 没有存储空间？
A：回到第 2 步，把"数据盘（GB）"设为 64 以上，点"同时创建两块硬盘"重建，再重新安装。

Q：画面里点鼠标没反应 / 点了没动静？
A：v1.9 起已内置 USB 绝对定位鼠标，正常情况下点哪里就是哪里。
   如果仍然点不动，按以下顺序试：
   1) 先点一下画面中间（不要点标题栏），让画面拿到焦点，再点按钮；
   2) 点画面右上角的「⧉ 弹出为独立窗口」，在独立窗口里操作
      （独立窗口模式下可按 Ctrl+Alt+G 捕获/释放鼠标）；
   3) 确认虚拟机是真的在运行（顶部显示"虚拟机运行中"）。

Q：很卡、很慢？
A：在 BIOS 里开启 Intel VT-x / AMD-V，或在"启用或关闭 Windows 功能"里
   勾选 Hyper-V 后重启电脑，软件会自动用硬件加速。

Q：新装的应用打不开 / 不知道该用什么地址访问？
A：应用跑在虚拟机里，需要把它的端口转发到本机才能用浏览器打开。
   1) 先确认应用使用的端口（飞牛「应用中心 → 该应用 → 详情」里能看到，
      或应用自己的设置页里显示，例如 qBittorrent 常用 8080、Jellyfin 8096）；
   2) 点左侧「⇄ 应用端口转发」，在「本机端口」填这个端口，
      点「添加并转发」——虚拟机运行中会立即生效，不用重启；
   3) 双击列表里那一行，或点「在浏览器打开」，地址是 http://localhost:端口。
   启动时已自动转发常见端口，所以多数应用装完直接 localhost:端口 就能打开。

Q：SSH 连不上 / 提示 connection refused？
A：飞牛默认不开 SSH，先在网页里打开开关：
   1) 浏览器登录 http://localhost:5666；
   2) 进入「设置 → SSH」（新版在「设置 → 安全 → SSH」）；
   3) 打开「启用 SSH 服务」，端口保持 22，保存。
   然后在本软件目录双击「SSH连接虚拟机.bat」，
   输入飞牛的用户名和密码即可（需要 root 权限时登录后执行 sudo -i）。
   对应的端口映射是：本机 2222 → 虚拟机 22。
   如果提示 connection refused / 连接被重置，说明 SSH 服务还没打开，
   或虚拟机没有启动。

Q：关掉软件后虚拟机会怎样？
A：退出软件时会询问是否关闭虚拟机。想保留运行状态就直接关窗口选"否"。
